# Quizzes

Active recall, not re-reading. Each question is something an interviewer could ask about a decision made in this codebase. Try to answer out loud **before** expanding the answer — the gap between "I recognise this" and "I can explain this" is exactly what an interview tests.

Questions are tagged by the level they'd typically be asked at:

<span class="diff diff--mid">Mid</span> &nbsp; <span class="diff diff--senior">Senior</span> &nbsp; <span class="diff diff--staff">Staff</span>

Topics are added here as they're built in the project — including ones already covered elsewhere, so this stays a single place to drill.

<div class="tip"><span>Answer first, expand second. If you can't explain the <em>why</em> and the <em>failure case</em>, you don't own it yet.</span></div>
